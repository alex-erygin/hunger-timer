# 🍴 Hunger Timer

Виджет на панели задач Windows 11 для правила «есть не раньше 2 часов после возникновения голода».

Клик по виджету запускает отсчёт 2:00:00, повторный клик — сброс. По истечении виджет зеленеет: «✅ Можно есть!». Состояние переживает перезапуск (localStorage).

## Особенности

- Виджет сидит прямо на панели задач, вплотную слева от системного трея (позиция вычисляется от реального rect `TrayNotifyWnd`).
- Не сворачивается по Win+D (tool window, `WS_EX_TOOLWINDOW`).
- Не перекрывается таскбаром (сторожок Z-порядка: проба `WindowFromPoint` раз в 300 мс, топмост только по факту перекрытия).
- Автоскрытие при полноэкранных приложениях (видео/игры, `SHQueryUserNotificationState`).
- Single instance: повторный запуск показывает и фокусирует существующее окно.
- Автозапуск с Windows — включён по умолчанию, отключается галочкой в меню трея (HKCU Run).
- Журнал событий для анализа использования (см. ниже).

## Статистика использования

Все события пишутся в `%APPDATA%\hunger-timer\events.jsonl` — по одной JSON-строке на событие:

```json
{"v":1,"ts":"2026-10-06T10:00:00.000Z","event":"timer_start","duration_ms":7200000}
```

| Поле    | Описание                                    |
|---------|---------------------------------------------|
| `v`     | версия схемы записи (при смене формата растёт) |
| `ts`    | время события, ISO 8601 UTC                  |
| `event` | тип события                                 |

Типы событий: `app_start` (поле `version`), `app_exit`, `timer_start` (`duration_ms`), `timer_finish` (`started_at`), `timer_reset` (`elapsed_ms`, `completed` — дождался ли конца отсчёта).

По `timer_start`/`timer_reset`/`timer_finish` можно анализировать, как часто возникает голод и как долго удаётся выдерживать 2 часа.

## Установка

Скачайте `hunger-timer_x.x.x_x64-setup.exe` из [Releases](../../releases) и установите.

## Сборка из исходников

Требуются: Node.js, Rust (MSVC), [Tauri prerequisites](https://tauri.app/start/prerequisites/).

```bash
npm ci
npm run tauri build
```

Релизы собираются автоматически GitHub Actions по тегу `v*`.

## Стек

Tauri v2 (Rust) + ванильный JS/HTML/CSS. Без фреймворков.
